# Project decisions log

Use this file to record decisions that may matter later for the final written report.

## v0.1

- Project scaffold created.
- Final visualization intentionally postponed until data feasibility is established.
- LEO working definition: altitude below 2,000 km.
- Planned analytical categories remain provisional until source values are audited.
- Historical launches and historical in-orbit population will be treated as distinct quantities.
- Collision probability will not be estimated directly from the catalogue data.
- The final visualization is expected to communicate congestion using transparent proxies rather than overclaiming risk.
